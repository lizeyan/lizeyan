# 时序异常检测｜基于极值理论的阈值选择

> 🚄 本文探讨了时序异常检测中的阈值选择问题，重点介绍基于极值理论（EVT）的无监督阈值选择方法。文章首先阐述了阈值选择在异常检测中的关键作用，然后详细讲解了极值理论的基础知识，包括 Fisher-Tippett 定理和广义极值分布。接着介绍了 POT 算法及其在 SPOT 系统中的应用，分析了初始阈值选择的多种方法。最后结合 ByteBrain 监控智能告警系统的实践案例，讨论了 EVT 在现实世界中的应用挑战与解决方案。

## 引言

在时序异常检测领域，无论我们使用何种技术手段，最终都面临一个关键问题：如何确定一个合适的阈值来区分正常与异常。这个问题的重要性不言而喻，它直接影响着异常检测系统的有效性和可靠性。

当我们编写监控规则（如 Prometheus 的 PromQL 或 Bosun 规则）时，需要为指标设定阈值。即使采用了先进的异常检测算法，如 Isolation Forest、LSTM、VAE 或 Transformer 等，这些算法最终输出的仅是异常分数，我们仍需确定一个阈值来决定是否触发告警。

阈值选择方法主要分为三类：

1. 人工选择：依赖专家经验，主观性强，难以大规模应用
2. 有监督自动选择：在标注数据集上优化检测准确率，但需要大量标注数据并定期更新
3. 无监督自动选择：不依赖标注数据，能够自适应数据特性
本文将聚焦于无监督自动选择方法，特别是基于极值理论（Extreme Value Theory， EVT）的阈值选择技术。在无监督领域，常见的方法包括拐点法（Elbow Point）、启发式规则（Heuristic Rules）以及基于 EVT 的方法。其中，EVT 方法具有坚实的数学基础，在实践中表现出广泛的适用性。

## 极值理论的基础原理

极值理论（EVT）是研究随机变量极端值统计行为的理论，为我们理解和预测罕见事件提供了数学框架。

极值理论的发展可追溯至 20 世纪 20 年代，由 Fisher 和 Tippett（1928）开创，随后由 Gnedenko（1943）完善了理论基础。20 世纪 70 年代，Pickands（1975）以及 Balkema 和 de Haan（1974）独立发展了超阈值方法（POT），大大拓展了极值理论的应用范围。近年来，随着计算能力的提升和大数据的出现，极值理论在金融风险管理、气象学、水文学以及计算机科学等领域得到了广泛应用。

EVT 的核心是 Fisher-Tippett 定理（FT 定理），也称为极值分布的三种类型定理。然而，Fisher-Tippett 定理存在许多局限，并不能直接用于实践。对于主要关注实践应用的读者，完全可以跳过定理的细节部分。

## Fisher-Tippett 定理

假设我们有一个独立同分布（i.i.d.）的随机变量序列 X 1 ,X 2 ,…,X n ，其共同的累积分布函数为 F(x) （即这 n 个随机变量是独立同分布的）。我们关心的是这些随机变量的最大值 M n =max(X 1 ,X 2 ,…,X n ) 在 n→∞ 时的极限分布。
